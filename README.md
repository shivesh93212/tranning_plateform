# Aptitude Platform

A responsive aptitude and DSA preparation platform.

## Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- FastAPI
- PostgreSQL
- Redis

### Payment
- Razorpay

## Features

- Company-wise aptitude questions
- Topic-wise practice
- Difficulty levels
- Instant answer validation
- Detailed explanations
- Progress tracking
- DSA company-wise questions
- LeetCode practice links
- Mock tests
- Subscription plans
- Responsive UI
- Admin question management
